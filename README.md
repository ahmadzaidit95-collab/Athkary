# 🕌 أذكاري | Athkary

تطبيق إسلامي بسيط يساعدك على المحافظة على الأذكار والأدعية اليومية بطريقة سهلة وهادئة.

## ✨ Features

- 🌅 أذكار الصباح
- 🌙 أذكار المساء
- 🤲 الأدعية
- 📿 المسبحة
- 🌗 الوضع الفاتح والوضع الغامق
- 🔍 البحث في أقسام الأدعية
- 🔢 عداد للأذكار
- 📱 واجهة عربية RTL
- 🎨 تصميم بسيط وهادئ وسهل الاستخدام

## 🛠️ Technologies

- Flutter
- Dart
- Material Design
- Provider
